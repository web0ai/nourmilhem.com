# Nour Milhem Portfolio

Static portfolio site for [nourmilhem.com](https://nourmilhem.com).

## Update

Edit `index.html` and the optimized files under `assets/`, then push to `main`. GitHub Pages deploys automatically.

## Agent handoff

- Canonical deployment source: this repository.
- Keep the current static, dependency-free architecture unless Nour approves a rebuild.
- Original high-resolution source assets are not stored here; only web-optimized assets are deployed.
- Preserve project titles, labels, credits, and contact links exactly unless Nour requests changes.
- Verify desktop and mobile layouts plus all media paths before publishing.
- Domain DNS is managed in Nour's GoDaddy account; never request or store her password.
